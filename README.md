Online Quiz Application

The Online Quiz Application is a web-based project designed to make learning more interactive and engaging. Users can select quiz categories, answer multiple-choice questions within a time limit, and view their performance instantly.

Technologies Used

- HTML5 – Structure
- CSS3 – Styling and responsive design
- JavaScript – Quiz logic and functionality
- Local Storage – Saving quiz scores

Key Features

- Multiple quiz categories
- Randomized questions and options
- Countdown timer
- Automatic score calculation
- Previous and next question navigation
- Answer review with explanations
- Local leaderboard

Purpose

This project demonstrates front-end web development concepts, JavaScript DOM manipulation, event handling, and browser Local Storage.
